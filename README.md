# Crime Oren

Open-world 3D-игра на Flutter/Dart, действие которой происходит в Южном районе
Оренбурга. Вид от третьего лица, вдохновлено современными open-world играми,
но со полностью оригинальными ассетами, кодом и миром.

## Технологический стек

- **Flutter 3.47+ (stable)** — управляется через [FVM](https://fvm.app), версия закреплена в `.fvmrc`.
- **[flutter_scene](https://pub.dev/packages/flutter_scene)** — realtime 3D-движок поверх Flutter GPU/Impeller: сцена-граф, glTF, PBR-материалы, физика, освещение.
- **OpenStreetMap → osm2world** — пайплайн получения геоданных Южного района и превращения их в игровой мир.

## Запуск

```sh
fvm flutter run --enable-flutter-gpu
```

Флаг `--enable-flutter-gpu` обязателен — без него 3D-сцена не рендерится.

## Архитектура

Модульная структура по игровым системам в `lib/`:

```
lib/
  core/        — общая инфраструктура (event bus, DI)
  engine/      — игровой цикл, Game-класс, debug-инструменты
  world/       — мир, чанки, террейн, стриминг
  player/      — контроллер игрока
  vehicles/    — транспорт и его физика
  weapons/     — оружие
  pedestrians/ — NPC-пешеходы
  police/      — система розыска
  traffic/     — транспортный AI
  physics/     — общие физические утилиты
  missions/    — миссии
  economy/     — деньги, магазины
  properties/  — недвижимость
  weather/     — погода
  time/        — время суток
  audio/       — звук
  ui/          — HUD, меню, адаптивные под ориентацию элементы управления
  save/        — сохранения
  data/        — загрузка data-driven конфигов (JSON)
  ai/          — AI пешеходов/полиции/трафика
```

Данные (характеристики машин, оружия, объектов мира) вынесены в `assets/data/*.json`,
а не зашиты в код.

## Пайплайн геоданных (OSM → 3D)

Реальная геометрия квартала (дома, дороги) вокруг дома игрока (ул. Весенняя, 3,
Южный район Оренбурга) получена из OpenStreetMap и сконвертирована в glTF
инструментом [osm2world](https://osm2world.org). Пайплайн лежит в
`tools/osm_pipeline/`:

```sh
cd tools/osm_pipeline
./setup_osm2world.sh   # один раз: скачивает osm2world (~470 МБ, не в git)
./fetch_osm_data.sh    # тянет дороги/здания через Overpass API
./convert_to_glb.sh    # конвертирует в assets/models/world/yuzhny_district.glb
```

Готовый `.glb` закоммичен в репозиторий — для обычной сборки игры сам
`osm2world` не нужен, только для пересборки/расширения геометрии.

## Разработка ведётся поэтапно

Проект строится как вертикальный срез: сначала небольшой рабочий кусок открытого
мира, затем — постепенное расширение систем.

### Статус

- [x] **Phase 1** — технический прототип: 3D-сцена, camera-relative управление
      персонажем, orbit-камера (drag), тач-джойстик, адаптивный под ориентацию
      HUD, FPS-оверлей. Проверено на Android/iOS симуляторах и на реальном iPhone.
- [x] **Phase 2 (начало)** — реальная геометрия квартала Южного района из OSM
      вместо плейсхолдер-земли.
- [x] **Phase 3 (начало)** — первая машина: kinematic-контроллер вождения
      (разгон, руление, занос на скорости в духе аркадного GTA-хендлинга),
      процедурный седан-плейсхолдер, посадка/высадка с переключением камеры.
      Полноценная rigid-body физика/подвеска и деформация кузова при столкновениях
      — отдельный будущий апгрейд на `flutter_scene_rapier`, когда тот выйдет
      из experimental-статуса.
- [ ] Дальше: полноценный дорожный граф для NPC/трафика, здания с интерьерами,
      визуальные повреждения кузова, пешеходы, полиция.
