# Crime Oren

Open-world 3D-игра на Flutter/Dart, действие которой происходит в Южном районе
Оренбурга. Вид от третьего лица, вдохновлено современными open-world играми,
но со полностью оригинальными ассетами, кодом и миром.

## Технологический стек

- **Flutter 3.47+ (stable)** — управляется через [FVM](https://fvm.app), версия закреплена в `.fvmrc`.
- **[flutter_scene](https://pub.dev/packages/flutter_scene)** — realtime 3D-движок поверх Flutter GPU/Impeller: сцена-граф, glTF, PBR-материалы, физика, освещение.
- **OpenStreetMap → osm2world** — пайплайн получения геоданных Южного района и превращения их в игровой мир.

## Запуск

```sh
fvm flutter run --enable-flutter-gpu
```

Флаг `--enable-flutter-gpu` обязателен — без него 3D-сцена не рендерится.

## Архитектура

Модульная структура по игровым системам в `lib/`:

```
lib/
  core/        — общая инфраструктура (event bus, DI)
  engine/      — игровой цикл, Game-класс, debug-инструменты
  world/       — мир, чанки, террейн, стриминг
  player/      — контроллер игрока
  vehicles/    — транспорт и его физика
  weapons/     — оружие
  pedestrians/ — NPC-пешеходы
  police/      — система розыска
  traffic/     — транспортный AI
  physics/     — общие физические утилиты
  missions/    — миссии
  economy/     — деньги, магазины
  properties/  — недвижимость
  weather/     — погода
  time/        — время суток
  audio/       — звук
  ui/          — HUD, меню, адаптивные под ориентацию элементы управления
  save/        — сохранения
  data/        — загрузка data-driven конфигов (JSON)
  ai/          — AI пешеходов/полиции/трафика
```

Данные (характеристики машин, оружия, объектов мира) вынесены в `assets/data/*.json`,
а не зашиты в код.

## Пайплайн геоданных (OSM → 3D)

Реальная геометрия квартала (дома, дороги) вокруг дома игрока (ул. Весенняя, 3,
Южный район Оренбурга) получена из OpenStreetMap и сконвертирована в glTF
инструментом [osm2world](https://osm2world.org). Пайплайн лежит в
`tools/osm_pipeline/`:

```sh
cd tools/osm_pipeline
npm install            # один раз: зависимости для нарезки на чанки (gltf-transform)
./setup_osm2world.sh   # один раз: скачивает osm2world (~470 МБ, не в git)
./fetch_osm_data.sh    # тянет дороги/здания через Overpass API
./convert_to_glb.sh    # конвертирует и режет на чанки в assets/models/world/chunks/
```

Реальная площадь полученного района — около 1900×1600 метров (весь Южный
район, а не один квартал), поэтому итоговая геометрия разбита на
пространственные ячейки (`grid_split.mjs`, размер — `chunkSizeMeters` в
`assets/data/world.json`) и грузится в игре только рядом с игроком
(`lib/world/district_streamer.dart`) — без этого рендер и коллизии считались
по всей геометрии сразу, независимо от видимости.

Готовый `.glb` закоммичен в репозиторий — для обычной сборки игры сам
`osm2world` не нужен, только для пересборки/расширения геометрии.

## Разработка ведётся поэтапно

Проект строится как вертикальный срез: сначала небольшой рабочий кусок открытого
мира, затем — постепенное расширение систем.

### Статус

- [x] **Phase 1** — технический прототип: 3D-сцена, camera-relative управление
      персонажем, orbit-камера (drag), тач-джойстик, адаптивный под ориентацию
      HUD, FPS-оверлей. Проверено на Android/iOS симуляторах и на реальном iPhone.
- [x] **Phase 2 (начало)** — реальная геометрия Южного района из OSM вместо
      плейсхолдер-земли (реальная площадь ~1900x1600 м), разбита на чанки
      и подгружается вокруг игрока (`lib/world/district_streamer.dart`);
      процедурная растительность там, где OSM ничего не разметил; дорожный
      граф из `highway=*` (`lib/world/road_graph.dart`) — по нему ходят
      NPC-пешеходы (`lib/pedestrians/`, простая state machine, один
      InstancedMesh на всех).
- [x] **Phase 3 (начало)** — машина: kinematic-контроллер вождения (разгон,
      руление, занос на скорости в духе аркадного GTA-хендлинга),
      посадка/высадка с переключением камеры; три процедурных силуэта
      (седан/хэтчбек/пикап, `VehicleArchetype` в `lib/vehicles/vehicle.dart`)
      — управляемая машина седан, хэтчбек+пикап припаркованы декоративно;
      уровень розыска 0-5 звёзд (`lib/police/wanted_system.dart`) —
      растёт от наезда на пешехода/превышения скорости, затухает со
      временем; патрульные машины (`lib/police/police_system.dart`)
      спавнятся при розыске (до 2 одновременно), едут к игроку по
      дорожному графу (`lib/police/road_pathfinding.dart`, Дейкстра, не
      напролом через здания), арест — контакт дольше 2 секунд, сбрасывает
      розыск и телепортирует игрока к точке спавна; визуальные
      повреждения кузова (`lib/vehicles/vehicle_damage.dart`) —
      переключение между 2-3 preset-мешами по накопленной силе ударов,
      не настоящая деформация геометрии. Полноценная rigid-body физика/
      подвеска и реальная деформация кузова при столкновениях — отдельный
      будущий апгрейд на `flutter_scene_rapier`, когда тот выйдет из
      experimental-статуса.
- [x] **Оптимизация под слабый Android** (19.09.2026) — на бюджетном
      RMX5303 было 3 FPS, стало 31 при ходьбе. Причины оказались не в
      Flutter, а в своих ошибках: плейсхолдер-земля красилась полноценным
      PBR с image-based lighting (92 мс кадра), а тени 220 неподвижных
      деревьев перерисовывались каждый кадр (46 мс). Появились пресеты
      качества (`assets/data/quality.json`, ТЗ раздел 23) и debug-панель
      замеров с разбивкой времени кадра на UI и GPU. Подробности и все
      замеры — в PROGRESS.md.
- [x] **Трафик и живой мир** (14.10.2026) — свой контроллер персонажа
      (кольцо лучей по ближним чанкам, не заходит в углы домов), фоновый
      трафик по правой полосе (`lib/traffic/`) со светофорами (розыск за
      проезд на красный), угон машин из потока, сбитые пешеходы падают и
      встают, деревья не растут в домах; пайплайн карты проверяет, что
      ни пешеходы, ни трафик не проходят сквозь здания
      (`tools/osm_pipeline/check_road_graph.mjs`).
- [x] **День и ночь** (14.10.2026) — солнце по реальной траектории для
      широты Оренбурга и дня года, закат, ночь с луной, светящиеся фары и
      окна, часы в HUD (`lib/time/`).
- [x] **Погода** (15.10.2026) — 10 состояний от ясно до метели с плавными
      переходами и сезонной сменой, дождь/снег/молнии, снег на земле;
      закаты и ночь в духе Вайс-Сити (лучи солнца, блики, неоновый
      грейдинг) — `lib/weather/`.
- [x] **Небо и неон** (15.10.2026) — своё небо на шейдере (реалистичные
      солнце, луна с фазами, звёзды), неоновые вывески на фасадах вдоль
      крупных улиц со светом на асфальте (`lib/world/neon_signs.dart`).
      Где остановились и следующий шаг — в PROGRESS.md, раздел

- [ ] Дальше: мокрый асфальт с отражениями, стрельба, деньги, дом,
