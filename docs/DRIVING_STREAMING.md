# Подгрузка района и контакт автомобиля — 18.11.2026

## Подгрузка

- StreamingWork объединяет запросы одного чанка и выполняет импорты по
  одному. Между задачами даёт завершиться кадру. Ближайший чанк идёт
  первым. Стартовая Game.load по-прежнему ждёт геометрию района до
  появления игрового управления.
- Завершившийся старый запрос не добавляет геометрию, если игрок уже
  уехал. Ещё не начатые устаревшие запросы пропускают чтение ассета.
- StreamingCenter имеет полосу 20 м у границы. Колебания вокруг линии
  сетки больше не догружают/выгружают один ряд туда-сюда. Большой
  телепорт сразу выбирает новую ячейку.
- Расстановка деревьев использует полную NavGrid. Проверяется вся
  круговая проекция кроны по квадратам ячеек: дороги/дома не должны
  попадать даже между прежними пятью лучами. При загрузке чанка больше
  нет сотен лучей по геометрии ради посадки деревьев. Для сценариев без
  готовой сетки прежняя проверка остаётся резервной.
- Земля использует ту же полосу у границ, общую сетку индексов и заранее
  выделенные массивы вершин. До 16 отсоединённых участков сохраняются
  для возврата (9 видимых + 16 в кеше), без неограниченного роста кеша.

## Проверки столкновений

Лучи камеры, персонажа и машины ограничены ближайшими чанками и
ближайшими автомобилями; подоконники/водостоки остаются визуальными.
Эксперимент с дополнительным отбором отдельных мешей не оставлен:
проверка не подтвердила преимущество. Используется прежний проверенный
обход геометрии выбранного чанка.

Корпус автомобиля проверяет четыре угла и середины четырёх сторон.
Каждая точка проходит от старого положения до нового с учётом поворота.
Проверяется боковой удар и угол, который движется к стене при вращении,
даже когда центр почти неподвижен. При ограничении перемещения также
ограничивается поворот. Аналитическая проверка стволов сохранена
отдельно и пока использует консервативный охват бампера.

## Четыре колеса

Опора определяется по четырём пятнам контакта вместо высоты под центром.
По ним строится плоскость положения кузова. Учитываются настоящие точки
осей модели: у нового седана они несимметричны относительно origin.
Отдельные колёса компенсируют остаточный перепад высоты в пределах
±18 см. Проверка на небольшом бугре под центром защищает от прежнего
подъёма всех колёс из-за одной центральной точки.

Новый стартовый седан имеет четыре независимых узла колёс. У старых
моделей с одним общим узлом задней оси визуальное перемещение задних
колёс остаётся общим; точки логической опоры всё равно четыре.

Это геометрическое следование земле с ограниченным ходом колёс, ещё не
полная 3D подвеска. Вертикальная динамика, отрыв от поверхности,
перевороты, двусторонние импульсы машин и деформации остаются отдельной
работой. Данные проверки не означают готовую физику GTA IV/V.

## Проверка

226 тестов прошли. Новые случаи: сериализация/объединение запросов,
продолжение очереди после ошибки, пропуск устаревшей работы, граница
сетки, диагональный угол дома под кроной, узкий тротуар, четыре опоры
на асимметричных осях, отдельная неровность под колесом, боковой удар,
вращающийся угол и быстрое перемещение через тонкую стену.

Runtime --smoke прошёл на iPhone 18 Pro Max, iOS 27.0. Колёса нового
седана находятся у земли, поворачивающийся кузов остаётся снаружи стены
реального дома (плоскость x≈7.05). Камера у стены, движение пешком,
посадка/разгон/торможение, дерево, рельеф и ручник тоже проверены.

Старый тест дерева иногда ставил зад машины внутрь соседнего дома:
выбиралось просто ближайшее дерево. Теперь тест выбирает свободный
подход для всего кузова, с проверкой домов и других стволов. Столкновения
не отключаются для smoke.

## Поездка для замера

```sh
fvm dart --packages=.dart_tool/package_config.json tools/qa/inspect_game.dart <VM-URL> --drive /tmp/crime-drive.json
```

Около 650 м по существующей дороге: (127,-502) → (173,184), целевая
скорость 13 м/с. Начальная подгрузка исключается короткой выдержкой.
Данные отрисованных кадров опрашиваются с перекрытием окон и
дедуплицируются по timestamp; сохраняются интервалы и траектория.

Для воспроизводимого замера отключены только коллизии с фоновыми
машинами: первый пробный проезд остановился в пробке. Сами машины,
пешеходы, геометрия, камера и подгрузка продолжают работать. Стены и
деревья участвуют в столкновениях. Это замер подгрузки на заданном
маршруте, а не испытание поведения в плотном трафике.

Первые прогоны по ходу разработки дали 58.4–59.4 FPS, но редкая пауза
около 100 мс оставалась. Они не являются строгим A/B: менялись состав
коллизий и условия разработки. Финальный прогон выполняется после всех
изменений, без одновременного запуска тестов/анализатора. Пресет high
и разрешение не снижались.

## Подготовка фасадов в очереди (18 ноября 2026)

Раньше очередь ждала только импорт GLB: обработчик после импорта запускал
асинхронную подготовку фасадов без ожидания. Теперь импорт, подготовка
материалов и добавление в сцену составляют одно задание. Между пакетами
подготовки отдаётся кадр: максимум четыре узла или мягкий бюджет 2 мс.
Одна операция не прерывается посередине, поэтому это не жёсткая гарантия
времени кадра. Материалы готовятся до монтажа; окна и мокрые дороги
регистрируются после него. Устаревшая подготовка отменяется при выгрузке.

Debug-диагностика хранит последние 512 замеров и Timeline-события по
этапам: base-import, detail-import, facade-material, facade-commit,
facade-preparation, attach, vegetation. Получение отчёта:
`fvm dart run tools/qa/inspect_game.dart <VM URL> --stream-stats /tmp/stream.json`.
Асинхронные длительности включают ожидание ресурсов и кадров; их нельзя
приравнивать к непрерывной блокировке главного потока. Синхронные commit,
attach и vegetation измеряются отдельно. Диагностика отключена в release.

Добавлены проверки ограничения пакетов, отмены между кадрами и ожидания
всей подготовки перед следующим импортом. Полный набор: 229 тестов.
Runtime smoke на iPhone 18 Pro Max прошёл, включая четыре колеса на
рельефе, ручник и поворот кузова возле настоящей стены.

Финальный проезд этого этапа: completed=true, 3023 кадра, 59.04 FPS,
p95 интервала 16.667 мс, p99 33.333 мс, максимум 70.839 мс; семь
интервалов >50 мс. Debug simulator, MacBook M1 Pro на батарее (56%),
без одновременных тестов/анализатора. Это отдельный замер, не доказательство
прироста относительно прошлой версии. Редкие паузы ещё остаются.
Последние 512 записей этапов после smoke и проезда: facade-commit до
0.12 мс, attach до 0.29 мс. facade-preparation до 198.51 мс включает
намеренные ожидания кадров. Эти времена не локализуют оставшиеся паузы
в рендерере/GPU и не доказывают их причину.
