# Управление и столкновения автомобилей

Параметры восьми моделей находятся в `assets/data/vehicles.json`.
Классический седан, современный седан, компакт, SUV, две спортивные машины,
такси и полиция различаются массой, разгоном, тормозами, сцеплением,
скоростью реакции руля и настройками подвески. Компакт проще удерживать
в повороте; самый быстрый спорткар требует более аккуратного газа.

Контакт учитывает массу, точку удара, вращение и трение. Машина может
отскочить от стены, скользить вдоль неё или передать импульс другой машине.
Сильный лобовой удар всё ещё резко гасит скорость — это ожидаемо.
Деревья проверяются по корпусу машины без прежнего лишнего буфера.

Удары создают локальные вмятины геометрии и потёртости. Общие исходные
модели не изменяются; обработка повреждений распределяется между кадрами.
Это приближённая плоская динамика с подвеской, а не полноценная 3D
симуляция деформируемого кузова: перевороты и отделяемые детали не реализованы.

Проверка работающей debug-сцены на macOS:

```sh
fvm dart run tools/qa/inspect_game.dart <vm-service-url> --vehicle-smoke
fvm dart run tools/qa/inspect_game.dart <vm-service-url> --smoke
```

Первый сценарий проверяет разные профили, удар о реальную стену,
изменение вершин кузова и передачу импульса между машинами.
Во время сценариев не вводить команды управления вручную.
