# Стартовый квартал

Восемь домов между Илекской и Сумской, севернее Весенней, оформлены
отдельными фасадными профилями. Контуры и адресные теги взяты из сохранённой
OSM-карты; цвета, материалы, входы, границы дворов и вся мелкая архитектура
— художественная интерпретация, а не результат обследования местности.
Эти элементы явно отмечены `placement: inferred` в данных.

Добавлены разные сочетания кирпича/штукатурки и металлических крыш,
оконные обрамления, двери с ручками, козырьки, ступеньки, почтовые ящики,
дымоходы и восемь входных светильников. Дворы получили деревянные или
металлические ограды с открытыми проходами, парковочные площадки,
хозяйственные сараи, кустарники и общий служебный проезд. Контейнерная
площадка размещена у южного края квартала. Две существующие декоративные
машины переставлены на дворовые парковки.

Светильники используют существующий пул из восьми ближайших прожекторов;
добавление входного света не увеличивает этот лимит. Дворы защищены от
случайного рельефа и процедурной посадки деревьев. Ограды имеют непрерывную
коллизию; проходы остаются открытыми. Двери, сараи и контейнеры статические,
интерьеров и открывания ворот пока нет.

Исходный рецепт: `assets/data/start_block.json`, генератор:
`python3 tools/osm_pipeline/build_start_block.py`. Затем последовательно:

```
node tools/assets/prepare_building_details.mjs assets/models/world/chunks assets/models/world/details
node tools/assets/prepare_city_streets.mjs
node tools/assets/check_start_block.mjs
node tools/assets/check_city_layout.mjs
node tools/assets/check_city_streets.mjs
python3 tools/osm_pipeline/render_city_plan.py
```

Проверка квартала связывает каждый профиль ровно с одним импортированным
домом, проверяет прилегание двери к стене и размещение парковки внутри
двора без пересечения дома. Общая проверка оград контролирует сохранение
картографированных дорожек. Dart-тесты дополнительно проверяют проходы
игрока через оба входа каждого двора.
